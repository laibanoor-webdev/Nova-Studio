# Nova Studio — Frontend Development Task

A responsive, editorial-style creative-studio website built for the Internee.pk frontend task using HTML, CSS, JavaScript, and a small React contact-form component.

## Visual direction
- Warm ivory, sage green, dusty rose, and soft clay palette
- Editorial serif headings paired with clean sans-serif body text
- Refined spacing, soft shadows, subtle hover movement, and responsive layouts

## Services highlighted
- Digital design
- Responsive frontend web development
- Branding and visual identity
- UI/UX design and interface planning
- SEO and performance
- Digital content

## Features
- Responsive layout for mobile, tablet, and desktop
- Mobile navigation menu with accessible state labels
- CSS animations, hover transitions, and scroll reveal effects
- Project category filters (All, Design, Web Development)
- React-powered contact form with client-side validation
- Success state after valid input (demo only; no backend/email is connected)
- Keyboard-friendly form labels and reduced-motion support

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Internet access is needed to load React/Babel and Google Fonts from their CDNs.

For the most reliable React/Babel behavior, use VS Code with the Live Server extension and open `index.html` through Live Server.

## Files
- `index.html` — page structure and React contact form
- `style.css` — layout, responsive styling, animation, and visual design
- `script.js` — mobile menu, project filters, and scroll reveal

## Important
This is a front-end demo. The form validates input in the browser and shows a confirmation screen, but does not send or store submissions. Replace the sample project content with your own details if required by your task instructions.


## Visitor review section
- Visitors can enter their name, select a 1–5 star rating, and leave written feedback.
- Reviews are saved in the current browser using localStorage for demonstration purposes.
- This is a frontend-only demo: reviews are not shared across visitors or sent to a server. A backend/database is needed for public reviews.
